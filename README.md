# Automated Traffic Light and Barrier System

This project is a miniature automated traffic management system developed using Arduino Uno. It uses three LEDs to represent traffic signals and a servo motor to control a barrier based on the current traffic light.

When the red light is activated, the barrier closes to stop vehicles. When the green light is activated, the barrier opens to allow vehicles to pass. The yellow light warns vehicles to prepare to stop before the cycle repeats.

## Components Used

- Arduino Uno
- Red, yellow and green LEDs
- MG90S servo motor
- 220Ω resistors
- Breadboard
- Jumper wires
- Arduino IDE

## Project Objectives

- Understand the fundamentals of Arduino programming.
- Learn how to integrate hardware and software.
- Demonstrate automatic traffic signal and barrier control.
- Develop practical skills in electronics and embedded systems.

## Future Improvements

- Vehicle detection using ultrasonic sensors.
- Traffic density-based signal timing.
- Emergency vehicle prioritisation.
- IoT-based remote traffic monitoring.

This project demonstrates how simple electronic components and programming can be combined to create a prototype for an automated traffic management system.
